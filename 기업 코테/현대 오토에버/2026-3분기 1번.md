### 처음 문제를 보고 생각한 자료구조 및 알고리즘

dp + 이분탐색

### 사용된 자료구조 및 알고리즘

dp + 이분탐색

### 걸린 시간

fail

### 나의 풀이

```java
import java.util.PriorityQueue;

class Solution {

    static class State {
        long endTime;    // 마지막 데이터 처리가 끝나는 시간
        long totalSize;  // 한 서버가 지금까지 처리한 데이터 크기 합

        State(long endTime, long totalSize) {
            this.endTime = endTime;
            this.totalSize = totalSize;
        }
    }

    public long solution(int[] dataSize, int[] processTime) {
        PriorityQueue<State> pq = new PriorityQueue<>(
            (a, b) -> Long.compare(a.endTime, b.endTime)
        );

        // 현재 데이터가 도착하기 전에 처리가 끝난 경로 중 최대 처리량
        long bestCompleted = 0;

        long answer = 0;

        for (int i = 0; i < dataSize.length; i++) {
            long arrivalTime = i;

            /*
             * 현재 데이터가 도착한 시각까지 처리가 끝난 상태들을 꺼낸다.
             *
             * endTime <= arrivalTime이면
             * 해당 서버는 현재 데이터를 바로 이어서 처리할 수 있다.
             */
            while (!pq.isEmpty()
                    && pq.peek().endTime <= arrivalTime) {

                State completed = pq.poll();

                bestCompleted = Math.max(
                    bestCompleted,
                    completed.totalSize
                );
            }

            /*
             * 현재 데이터를 처리하는 서버의 최대 누적 처리량
             *
             * 이전에 끝난 가장 좋은 경로 뒤에
             * 현재 데이터를 이어 붙인다.
             */
            long currentTotal =
                    bestCompleted + dataSize[i];

            long endTime =
                    arrivalTime + processTime[i];

            pq.offer(new State(endTime, currentTotal));

            answer = Math.max(answer, currentTotal);
        }

        return answer;
    }
}
```

처음에 프로그래머스의 입국심사문제와 유사해서 이분탐색과 dp로 풀려고 하다가 너무 어려워서 포기했었다.
