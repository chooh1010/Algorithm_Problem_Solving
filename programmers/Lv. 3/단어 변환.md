### 처음 문제를 보고 생각한 자료구조 및 알고리즘

BFS

### 사용된 자료구조 및 알고리즘

BFS

### 걸린 시간

20분

### 나의 풀이

```java
import java.util.*;

class Solution {
    
    public int BFS(String begin, String target, String[] words){
        int[] ch = new int[words.length];
        int L=0;
        Queue<String> Q = new LinkedList<>();
        Q.offer(begin);
        while(!Q.isEmpty()){
            int len = Q.size();
            for(int i=0;i<len;i++){
                String wordQ = Q.poll();
                if(wordQ.equals(target)) return L;
                for(int j=0;j<words.length;j++){
                    int idx = 0;
                    for(int k=0;k<wordQ.length();k++){
                        if(wordQ.charAt(k)==words[j].charAt(k)) idx++;
                    }
                    if(idx==wordQ.length()-1&&ch[j]==0){
                        ch[j] = 1;
                        Q.offer(words[j]);
                    }
                }
            }
            L++;
        }
        return 0;
    }
    
    public int solution(String begin, String target, String[] words) {
        int answer = BFS(begin, target, words);
        return answer;
    }
}
```

BFS로 큐에 있는 단어와 1글자빼고 일치하면 체크하고 큐에 넣어서 target이 나올때까지 반복하고 변환한 횟수를 리턴했다.
