### 처음 문제를 보고 생각한 자료구조 및 알고리즘

Union/Find

### 사용된 자료구조 및 알고리즘

Union/Find

### 걸린 시간

25분

### 나의 풀이

```java
import java.util.*;

class Solution {
    static int[] unf;
    
    public int find(int a){
        if(unf[a]==a) return a;
        else return unf[a] = find(unf[a]);
    }
    
    public void union(int a, int b){
        int fa = find(a);
        int fb = find(b);
        if(fa!=fb) unf[fa] = fb;
    }
    
    public int solution(int n, int[][] computers) {
        int answer = 0;
        unf = new int[n+1];
        for(int i=1;i<=n;i++){
            unf[i] = i;
        }
        for(int i=0;i<n;i++){
            for(int j=i+1;j<n;j++){
                if(computers[i][j]==1&&i!=j) union(i+1 ,j+1); 
            }
        }
        HashSet<Integer> hs = new HashSet<>();
        for(int i=1;i<=n;i++){
            hs.add(find(i));
        }
        return hs.size();
    }
}
```

Union/Find로 풀면 쉽게 풀린다.
