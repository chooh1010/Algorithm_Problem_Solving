### 처음 문제를 보고 생각한 자료구조 및 알고리즘

해시맵

### 사용된 자료구조 및 알고리즘

해시맵

### 걸린 시간

50분

### 나의 풀이

```java
import java.util.*;

class Genre implements Comparable<Genre>{
    public String name;
    public int play;
    
    public Genre(String n, int p){
        name = n;
        play = p;
    }
    
    @Override
    public int compareTo(Genre o){
        return o.play - this.play;
    }
}

class Song implements Comparable<Song>{
    public int id;
    public String genre;
    public int play;
    
    public Song(int i, String g, int p){
        id = i;
        genre = g;
        play = p;
    }
    
    @Override
    public int compareTo(Song o){
        return o.play - this.play;
    }
} 

class Solution {
    public int[] solution(String[] genres, int[] plays) {
        ArrayList<Genre> gList = new ArrayList<>();
        ArrayList<Song> sList = new ArrayList<>();
        HashMap<String, Integer> gHm = new HashMap<>();
        for(int i=0;i<genres.length;i++){
            gHm.put(genres[i], gHm.getOrDefault(genres[i], 0) + plays[i]);
            sList.add(new Song(i, genres[i], plays[i]));
        }
        for(String s:gHm.keySet()){
            gList.add(new Genre(s, gHm.get(s)));
        }
        Collections.sort(gList);
        Collections.sort(sList);
        ArrayList<Integer> answer = new ArrayList<>();
        for(Genre g:gList){
            int i=0;
            for(Song s:sList){
                if(g.name.equals(s.genre)){
                    answer.add(s.id);
                    i++;
                }
                if(i==2) break;
            }
        }

        return answer.stream().mapToInt(i->i).toArray();
    }
}
```

해시맵으로 각 장르별 play수의 합을 구한 뒤 list에서 play 수 순으로 내림차순 정렬 후

노래들의 play순으로 내림차순한 list에서 장르 play순 내림차순으로 장르별 2개씩 play많은 노래순으로 답에 넣음.
