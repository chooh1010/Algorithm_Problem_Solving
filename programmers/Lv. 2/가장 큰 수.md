### 나의 풀이

```java
import java.util.*;

class Solution { 
    public String solution(int[] numbers) {
        String[] stringNum = new String[numbers.length];
        for(int i=0;i<numbers.length;i++){
            stringNum[i] = String.valueOf(numbers[i]);
        }
        Arrays.sort(stringNum, (a, b) -> (b + a).compareTo(a + b));
        if(stringNum[0].equals("0")) return "0";
        StringBuilder sb = new StringBuilder();
        for(int i=0;i<stringNum.length;i++){
            sb.append(stringNum[i]);
        }
        return sb.toString();
    }
}
```

처음에 DFS로 이어 붙여 만들수 있는 모든 수를 list에 저장한다음에 정렬해서 구하려고 했는데 메모리 초과
