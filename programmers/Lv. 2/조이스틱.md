### 나의 풀이

```java
class Solution {
    public int solution(String name) {
        int answer = 0;
        int[] cntArr = new int[26];
        for(int i=0;i<26;i++){
            cntArr[i] = i;
        }
        for(int i=25;i>=0;i--){
            if(cntArr[i]>26-i) cntArr[i] = 26-i;
        }
        for(char c:name.toCharArray()){
            answer += cntArr[c-'A'];
        }
        int n = name.length();
        int move = n-1;
        for(int i=0;i<n;i++){
            int next = i+1;
            while(next<n&&name.charAt(next)=='A'){
                next++;
            }
            move = Math.min(move, i*2 + (n-next));
            move = Math.min(move, (n-next)*2 + i);
        }
        
        return answer + move;
    }
}
```

처음에 커서이동을 생각하지못하고 풀었다. 커서이동을 생각하면 연속적인 A범위를 구하고 연속적인 A 뒤의 문자에 도달하기 위해 오른쪽 먼저 하고 왼쪽으로 갈건지 왼쪽먼저하고 오른쪽으로 갈건지 더 작은 값을 구해야한다.
