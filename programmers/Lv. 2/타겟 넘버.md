### 처음 문제를 보고 생각한 자료구조 및 알고리즘

DFS

### 사용된 자료구조 및 알고리즘

DFS

### 걸린 시간

10분

### 나의 풀이

```java
class Solution {
    static int n;
    static int t;
    static int answer;
    
    public void DFS(int L, int[] numbers, int sum){
        if(L==n){
            if(sum==t) answer++;
        }else{
            DFS(L+1,numbers,sum+numbers[L]);
            DFS(L+1,numbers,sum-numbers[L]);
        }
    }
    
    public int solution(int[] numbers, int target) {
        answer = 0;
        n = numbers.length;
        t = target;
        DFS(0, numbers, 0);
        
        return answer;
    }
}
```

더하거나 빼는 경우밖에 없으므로 for문과 ch 배열을 사용하지 않았다.
