### 처음 문제를 보고 생각한 자료구조 및 알고리즘

완탐

### 사용된 자료구조 및 알고리즘

완탐

### 걸린 시간

10분

### 나의 풀이

```java
class Solution {
    public int[] solution(int brown, int yellow) {
        int[] answer = new int[2];
        for(int i=3;i<brown/2;i++){
            boolean flag = false;
            for(int j=3;j<brown/2;j++){
                if(isTrue(i,j,brown,yellow)){
                    if(i>=j) {
                        answer[0] = i;
                        answer[1] = j;
                    }else{
                        answer[0] = j;
                        answer[1] = i;
                    }
                    flag = true;
                    break;
                }
            }
            if(flag) break;
        }
        return answer;
    }
    public boolean isTrue(int a, int b, int brown, int yellow){
        return brown == a*2 + (b-2)*2 && yellow == (a-2)*(b-2);
    }
}
```

가로크기와 세로크기를 모두 돌면서 isTrue에 만족하면 답에 넣었다.
