### 나의 풀이

```java
import java.util.*;

class Solution {
    public long solution(int n, int[] times) {
        long answer = 0;
        Arrays.sort(times);
        long lt = 1;
        long rt = (long)times[times.length-1]*n;
        while(lt<=rt){
            long mid = (lt+rt)/2;
            if(count(mid, times)>=n){
                answer = mid;
                rt = mid-1;
            }else{
                lt = mid+1;
            }
        }
        return answer;
    }
    public long count(long mid, int[] times){
        long count = 0;
        for(int time:times){
            count += mid / time; 
        }
        return count;
    }
}
```

처음에 count메서드를 구현할때 dp로 구하려고해서 int배열에 mid가 넣어지지않아서 실패했다. 그냥 mid / time으로 구하는게 맞았다. 그리고 count를 long으로 바꿔야했고 long rt = (long)times[times.length-1]*n; 이부분도 times[times.length-1]와 n모두 int이기때문에 하나라도 long으로 바꿔서 계산해야 오버플로우가 발생하지 않는다.
