### 사용된 자료구조 및 알고리즘

### 나의 풀이

```java
import java.util.*;

class Solution {  
    static Set<Integer> numberSet;
    static int[] ch;
    static int n;
    
    public boolean isDicimal(int number){
        if (number < 2) {
            return false;
        }
        
        for(int i=2;i * i<=number;i++){
            if(number%i==0) return false;
        }
        return true;
    }
    
    public void DFS(String[] numArray, StringBuilder sb){
        if(sb.length()>0){
            int number = Integer.parseInt(sb.toString());
            if(isDicimal(number)) numberSet.add(number);
        }
        for(int i=0;i<n;i++){
            if(ch[i]==0){
                ch[i] = 1;
                String num = numArray[i];
                sb.append(num);
                DFS(numArray,sb);
                sb.delete(sb.length()-num.length(), sb.length());
                ch[i] = 0;
            }
        }
        
    }
    
    public int solution(String numbers) {
        int answer = 0;
        String[] numArray = numbers.split("");
        numberSet = new HashSet<>();
        ch = new int[numArray.length];
        n = numArray.length;
        StringBuilder sb = new StringBuilder();
        DFS(numArray, sb);
        return numberSet.size();
    }
}
```

처음에 DFS로 모든 경우의 수를 구하려고 했는데 L==n일때만 구하니까 sb에 n자리수만 들어가 있어서 실패했다.

sb.length()>0를 걸어두니 모든 경우의 수를 구할 수 있었다. 중복은 HashSet으로 제거할 수 있었다.
